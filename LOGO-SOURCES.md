# Client logo sources

These five client cards use remote logo artwork instead of the badly cropped company-profile PDF images. Internet access is required for the artwork; if a source blocks loading, the client name appears as a fallback.

- jollibee: https://commons.wikimedia.org/wiki/Special:FilePath/Jollibee_2011_wordmark.svg
- toyota: https://logo.clearbit.com/toyota.com?size=512
- ajinomoto: https://commons.wikimedia.org/wiki/Special:FilePath/Ajinomoto_global_logo.svg
- gfk: https://logo.clearbit.com/gfk.com?size=512
- apcargo: https://logo.clearbit.com/apcargo.com.ph?size=512

For fully offline deployment, replace these remote URLs with licensed local PNG/SVG files.
